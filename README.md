# devsecops-juice-shop-pipeline
Este repositório demonstra um pipeline DevSecOps , integrando ferramentas de segurança (SAST, DAST, SCA e IaC scanning) em um pipeline CI/CD com Jenkins. Como alvo de testes, utiliza o OWASP Juice Shop, uma aplicação web intencionalmente vulnerável mantida pela OWASP para fins de aprendizado e prática em segurança de aplicações.
